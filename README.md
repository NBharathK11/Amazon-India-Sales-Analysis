# Amazon India Sales Analysis & Business Performance Dashboard

## 📌 Project Overview

This project analyzes Amazon India sales data to understand overall business performance across sales, profit, products, orders, order status, payment methods, fulfillment methods, and geographic performance.

The analysis was developed as part of an internship assignment and is designed to present business information in a simple and understandable format for a non-technical manager.

The project answers four key Business Questions (BQ1–BQ4) using Microsoft Excel and PivotTables.

---

## 🎯 Project Objective

The main objective of this project is to analyze Amazon India sales data and extract meaningful business insights related to:

- Sales performance
- Profitability
- Orders and units sold
- Category and product performance
- Order status
- Returns and cancellations
- Payment methods
- Fulfillment methods
- State-wise business performance

The analysis helps understand which areas contribute to business performance and where revenue loss or operational issues may exist.

---

## 📊 Dataset

The project uses an Amazon India sales dataset containing order-level transaction information.
